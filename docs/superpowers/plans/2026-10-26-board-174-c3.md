# Board #174 C3: Card detail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Both apps get the full card detail from #174 Part 2:
- a drawer with a full-page toggle and a default setting;
- every property: start/due quick picks, estimate, blocked-by/blocks, custom fields, links;
- a Markdown description toolbar;
- subtask reorder and "Convert to card";
- correct comment authors;
- a More menu, also on right-click;
- a New card modal (⌘N).

**Architecture:**
- **Store:** board-store gains the missing operations: subtask move, convert subtask, duplicate card, move card to another board.
- **Plumbing:** both apps gain wrappers or commands for every store function the detail needs.
- **UI:** each app's drawer is extended in two passes, then the New card modal.

**Tech Stack:** Rust (board-store, gespan-core, GPUI, src-tauri), React, Vitest, Bun.

**Spec:** #174 Part 2 ("Card detail"). Parent plan `docs/superpowers/plans/2026-10-25-board-174.md` (Phase C row C3). Map: `docs/superpowers/plans/2026-10-26-board-174-c3-maps.md`.

## Global Constraints

- Same branch and single PR. Commits plain, no tool attribution.
- **Storage:** all writes go through `gespan-board-store`, positions stay contiguous, and each change writes one activity row (none on a no-op).
- **Date quick picks** (start and due): Today, Tomorrow, Next week (+7 days), In 2 weeks (+14 days), Clear, plus a date input. All values are stored as local-midnight epoch ms.
- **Estimate:** entered as minutes or `1h 30m` / `90m` / `2h`; shown as `1h 30m`; range 1 to 6,000,000 minutes (store limit).
- **Relations:**
  - "Blocks" writes `blocks` (this card → other).
  - "Blocked by" writes `blocks` (other → this card).
  - "Relates to" writes `relates`.
  - Cycles are refused with the store message.
  - The picker lists cards on the same board by `#N Title`.
- **Custom fields:** the drawer shows and edits values for the board's existing fields (kinds text, number, date, select, checkbox). Managing fields arrives in C5.
- **Links list:** shows `card_links` (session, pilot, flow-run, pr, worktree), each with Open and Remove. Add offers session and pilot pickers, plus a PR URL or worktree path text entry. The ticket keeps its own row.
- **Markdown toolbar** (exact behaviour):

  | Button | Effect |
  |---|---|
  | Bold | wraps the selection in `**…**` |
  | Italic | wraps the selection in `_…_` |
  | Heading | prefixes the line with `## ` |
  | Bulleted list | prefixes the selected lines with `- ` |
  | Numbered list | prefixes the selected lines with `1. `, `2. `… |
  | Link | turns the selection into `[selection](url)` with `url` selected |
  | Code | wraps in `` `…` `` for one line, in a fenced block for several |

  With no selection, it inserts the markers and puts the cursor between them. The stored text is plain Markdown.
- **Convert to card** (one transaction):
  - a new card goes in the parent's column, right after the parent, titled with the subtask title;
  - a `relates` relation links it to the parent;
  - the subtask is deleted.
  - Activity on the parent: "subtask converted: T → #M".
- **Duplicate:**
  - "{title} (copy)", right after the original;
  - copies body, priority, due, start, estimate, labels, projects, subtasks (all reset to not done) and custom field values;
  - does not copy links, ticket, comments or relations.
  - Activity on the copy: created, "duplicated from #N".
- **Move to board:**
  - goes to the end of the target board's first `todo` column, else its first column;
  - gets a new number on the target board;
  - labels map by case-insensitive name (otherwise dropped);
  - field values map by name and kind (otherwise dropped);
  - relations are removed;
  - links, ticket, comments, subtasks and meta are kept.
  - Activity rows go on both boards ("moved to board X" / "moved from board Y").
- **More menu**, also on card right-click, with these items in order:
  1. Open
  2. Status…
  3. Priority…
  4. Labels…
  5. Move to board…
  6. Copy link
  7. Copy `#N Title`
  8. Duplicate
  9. Archive
  10. Delete

  Archive and Delete use the undo toast from C2. "Copy link" copies `gespan://board/{board_id}/card/{card_id}`. In-app routing of that link is out of scope.
- **Comment authors:** "You" for `user` and "Agent" for `agent`, in both apps, with distinct avatars.
- **Full page:** a toggle in the drawer's top bar expands the detail to fill the board area (Escape or the toggle returns to the drawer). The default setting is "Open cards in": Drawer / Full page, stored as Native setting `board-card-open` and Tauri flag `gespan.boardCardOpen`.
- **New card modal:**
  - ⌘N (Ctrl+N on Windows/Linux) while the board has focus. Native binds it in a `Board` key context, so it doesn't collide with the workspace ⌘N.
  - Fields: title (required), column, priority, due, labels, projects, description.
  - "Create more" checkbox: after creating, the modal stays open with the title cleared and the other fields kept.
  - ⌘↵ submits, Escape closes.
- Verification before each commit: `bun run check`, and `bun run native:check` when crates/ changes.

## Review Focus

1. **Moving a card to a board that has a label with the same name in different case, or no columns with role `todo`.** It must map the label and land in the first column, never fail or drop data unannounced. Tests in C3-1.
2. **Convert to card when the parent sits at the end or start of the column, or when the subtask was deleted elsewhere.** Positions stay contiguous and the error is clear. Tests in C3-1.
3. **The Markdown toolbar with a selection spanning several lines, an empty selection, or a selection at the end of the text.** Exact output strings. Tests in C3-4 and C3-7.
4. **⌘N when focus is in a text field, such as the search box or the composer.** It must still open the modal, and must not type an "n" or collide with the workspace shortcut. Tests in C3-5 and C3-8.
5. **A relation picker that would create a cycle.** It shows the store's refusal inline and writes nothing. Tests in C3-3 and C3-6.
