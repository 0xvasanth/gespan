# Board #174 C2: Board view Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Both apps get the board-view features from #174 Part 2:
- quick edits on the card face;
- a column menu (collapse, sort once, mark all done, archive completed);
- quick add that stays open;
- undo toasts for moves, deletes, archives and bulk actions;
- an Archive view.

**Architecture:**
- **Store:** board-store gains `restore_card` (unarchive back to an exact slot) and `archive_cards`.
- **Plumbing:** Native's `Service` and Tauri's commands expose archive, restore, move and column-display operations.
- **Undo:** each app keeps a small undo controller. It holds one pending inverse operation for 8 s.
- **Deletes:** deletes are held. The card is archived at once, then permanently deleted when the toast expires, or restored on Undo.

**Tech Stack:** Rust (board-store, gespan-core, GPUI, src-tauri), React + dnd-kit, Vitest, Bun.

**Spec:** #174 Part 2 ("Board view"). Parent plan `docs/superpowers/plans/2026-10-25-board-174.md` (Phase C row C2). Map: `docs/superpowers/plans/2026-10-26-board-174-c2-maps.md`.

## Global Constraints

- Same branch and single PR. Commits plain, no tool attribution.
- All storage through `gespan-board-store`. Positions stay contiguous `0..n-1` for live cards.
- **Undo window: 8 seconds.** One toast at a time. A new undoable action replaces the toast, and a pending delete from the replaced toast is committed immediately.
- **Toast copy** (exact strings):
  - "Moved #N to {column}"
  - "Moved N cards to {column}"
  - "Archived #N"
  - "Archived N cards"
  - "Deleted #N"
  - "Sorted {column}"

  Each has an "Undo" button. Undo of a delete restores the card to its column and index.
- **Held delete:** delete archives the card at once, so it is hidden from the board and not listed in the Archive view while pending. When the toast expires, the card is permanently deleted (`delete_card`). If the app quits before then, the card stays archived and appears in the Archive view, so nothing is lost silently.
- **Delete column** is allowed only when the column has no live and no archived cards. The disabled reason reads "Move or delete its N cards first" (N counts archived cards).
- **Sort once:** order by priority (Urgent first; ties keep current order) or by due date (soonest first; no due date last). One `move_cards` write.
- **Mark all as done:** move every live card in the column to the board's `done` column (the first column with role `done`). The menu item is hidden when the column is the done column or when none exists.
- **Archive completed:** only on the `done` column. Archives every live card in it.
- **Collapsed column:** a 36 px strip showing the rotated name and count. It still accepts card drops (mouse and keyboard). Click or Enter expands it. State is persisted through `set_column_display`, passing the current colour and WIP limit back unchanged.
- **Quick edits on the card face:** clicking priority, due or labels opens a small menu in place. An unprioritised card shows a faint priority target on hover. These controls must never start a drag or open the card.
- Verification before each commit: `bun run check`, and `bun run native:check` when crates/ changes.

## Review Focus

1. **Undo after the board changed underneath** (the other app or an agent moved or deleted the card during the 8 s). Undo must restore what it can and report what it couldn't ("Couldn't undo: the card was deleted"), never crash or duplicate. Tests in C2-3 and C2-5.
2. **The app quitting or switching boards while a delete is pending.** On board switch the pending delete commits. On quit the card stays archived, never half-deleted. Tests in C2-3 and C2-5.
3. **Dropping onto a collapsed column**, by mouse and keyboard. The card lands at the end of that column. Tests in C2-2 and C2-4.
4. **Sort once with filters active.** It sorts the whole column, not only visible cards, and undo restores the exact previous order. Tests in C2-2 and C2-4.
5. **Quick-edit clicks on the card face** must not start a drag, open the drawer or move focus away unexpectedly. Tests in C2-2 and C2-4.

### Task C2-1: Store, Native service and Tauri plumbing

**Files:**
- Modify: `crates/board-store/src/meta.rs` (or a new `crates/board-store/src/archive.rs`), `crates/board-store/src/lib.rs`, `crates/gespan-core/src/board/mod.rs` and/or `extras.rs`, `src-tauri/src/board.rs`, `src-tauri/src/lib.rs`, `src/features/board/model/board.ts`
- Test: `crates/board-store/tests/v3.rs`, `src-tauri/src/board.rs` tests, `src/features/board/model/board.test.ts`

**Interfaces:**
- Produces in board-store:
  - `pub fn restore_card(conn, card_id: &str, column_id: &str, index: usize) -> Result<String, String>`. In one write transaction: unarchive, then place at `index` (clamped) in `column_id`. Logs "unarchived" (and "moved" only if the column differs from the archived one). Errors "Card not found" if gone, "Column not on this board" if the column was deleted.
  - `pub fn archive_cards(conn, card_ids: &[String]) -> Result<String, String>`. One transaction, one "archived" activity row per card that changed. All cards must be on one board.
  - `pub fn column_card_count(conn, column_id: &str) -> Result<(usize /*live*/, usize /*archived*/), String>`.
- Produces in gespan-core `Service`:
  - `archive(card_id)`, `archive_many(&[String])`, `unarchive(card_id)`, `restore(card_id, column_id, index)`, `archived(board_id) -> Vec<Card>`
  - `move_many(&[String], column_id, index, actor)`
  - `set_column_display(column_id, color: Option<&str>, wip_limit: Option<i64>, collapsed: bool)`
  - `column_card_count(column_id) -> (usize, usize)`
- Produces in Tauri:
  - commands `board_card_archive`, `board_cards_archive(cardIds)`, `board_card_unarchive`, `board_card_restore(cardId, columnId, index)`, `board_archived_cards(boardId) -> Vec<Card>`, `board_cards_move(cardIds, columnId, index, actor)`, `board_column_set_display(columnId, color, wipLimit, collapsed)`, `board_column_card_count(columnId) -> {live, archived}`;
  - TS wrappers `archiveCard`, `archiveCards`, `unarchiveCard`, `restoreCard`, `listArchivedCards`, `moveCards`, `setColumnDisplay`, `columnCardCount`.
